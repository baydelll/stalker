# Интерактивный лонгрид «Где твой сталкер?»

Запустите папку через VS Code → Live Server либо локальный HTTP-сервер: `python -m http.server 8000` и откройте `http://localhost:8000`.

Файлы: `index.html` — все экраны и тексты; `style.css` — полностью кодовая вёрстка, без подложки полного SVG; `script.js` — переходы, анимация, чат, три раунда выбора, камеры и микрофон, таймер; `assets/` — только отдельные фотографии.

Навигация: прокрутка вниз / пробел / стрелка вниз / свайп вверх. В чатах один жест прокрутки открывает одно сообщение. Тексты печатаются по буквам. Варианты ответов требуют подтверждения. В тестах блокируется дальнейшая прокрутка до правильного ответа; две ошибки сбрасывают тест. Третий тест требует найти **две** фотографии.

Разрешения: видеокамера запрашивается после подтверждения первого ответа «Дома есть кто-то помимо тебя?»; микрофон — при выборе картинки во втором раунде. Потоки сразу останавливаются; данные никуда не передаются. Браузер требует localhost или HTTPS для запросов. Пользователь может отказать, сюжет продолжится.

Уведомление: звук программно синтезируется через Web Audio API; это похожий трёхтональный сигнал, **не оригинальный защищённый звук Telegram**. Браузер может блокировать звук до первого взаимодействия с сайтом.

Примечание по исходникам: SVG-макет не встроен в сайт. Фотографии выделены как изображения. Текст в дизайнерском SVG преобразован в кривые и не восстанавливается автоматически как текст, поэтому отдельные повествовательные фрагменты реконструированы по визуальному макету и могут потребовать буквальной сверки с исходным авторским текстом. Некоторые изображения в третьем наборе требуют ручной проверки с исходными номерами позиций.


ИЗМЕНЕНИЯ V3: Реплики обоих чатов и время сообщений сверены с SVG. Таймер двери запускается при входе на экран и работает 15 секунд. Информационные блоки размещены асимметрично и после появления остаются видимыми, двигаясь вверх при следующей прокрутке. Текст статуса разрешений скрыт.

ЗВУК: файл уведомления не был доступен среди загруженных исходников. Для точного пользовательского звучания сохраните присланный звук как assets/stalker-notification.mp3 (формат MP3). Код автоматически его подхватит, когда файл будет добавлен. Пока файла нет, работает прежний синтезированный сигнал.


## Изменения V6
- Каждое слово исходного текста сохраняется; типографские неразрывные пробелы не заменяют слова.
- По прокрутке открываются три слова за раз, затем дополнительный шаг для чтения, затем следующий текст/экран.
- Одновременно виден только один информационный блок.
- Отменены плавающие чёрные карточки и хаотичные слова.
- Звук tick.wav стал выше по частоте и более отчётливым.


V7: финальное меняющееся слово только красное, без белой подложки; после таймера только «Время вышло.»; дополнительные сюжетные запросы: микрофон после выбора ответа о двери, камера после повторного выбора, один ли пользователь дома. Браузер может не показать повторное окно при ранее сохранённом разрешении. Потоки немедленно останавливаются, запись/отправка не ведутся.
